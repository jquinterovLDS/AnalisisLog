README
1. Requisitos previos, Descargar instalar:
		Python
		VS Code
	
2. REINICIAR
	
3. Abrir VsCode 
	Abrir la carpeta, donde esta el proyecto 

4. Estructura de carpetas:
	proyecto_logs/
	├── logs/          # Aquí van los archivos .log a analizar
	├── resultados/    # Se crea automáticamente (no necesita preparación)
	├── img/           # Contiene logoGif.png para el dashboard
	├── analisis_unificado.py
	└── dashboard.py
	
	Abrir "analisis_unificado.py"
	ejecutar el proyecto '|>' , saca error e instalar componentes desde terminal
	
	pip install pandas matplotlib plotly streamlit
	python.exe -m pip install --upgrade pip
	

	
3. Pasos para ejecutar:

	Colocar los archivos de log en la carpeta logs/

	Ejecutar primero el análisis:
		python analisis_unificado.py
	
	Luego ejecutar el dashboard:
	streamlit run dashboard.py
